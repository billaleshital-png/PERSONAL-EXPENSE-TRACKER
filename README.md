# 💰 PERSONAL EXPENSE TRACKER

## 📌 Project Description

Personal Expense Tracker is a simple Python-based application used to record, manage, and track daily expenses.

The project allows users to add expenses, view all expenses, calculate total expenses, check category-wise spending, and manage a monthly budget.

## 🚀 Features

- ➕ Add new expenses
- 📋 View all expenses
- 💰 Calculate total expenses
- 📊 Calculate category-wise expenses
- 💵 Check monthly budget
- 📁 Store expense data in CSV file
- ⚠️ Validate invalid amount and budget inputs
- 📅 Automatically record the current date

## 🛠️ Technologies Used

- Python 3
- CSV File Handling
- Functions
- Loops
- Dictionaries
- Conditional Statements
- Exception Handling
- Date and Time
